# 🔄 Code-to-Flowchart Generator

An interactive web application that automatically transforms pseudocode and code snippets into clean, visual flowcharts. 

---

## 🌟 Overview

Understanding complex code structures or logic flows can be challenging. The **Code-to-Flowchart Generator** simplifies this process by parsing code structure and visualizing it as a flow diagram in real time. It is designed to help students, developers, and educators analyze algorithms effortlessly.

---

## ✨ Features

- ⚡ **Instant Generation:** Converts pseudocode into visual diagrams in real time.
- 🎨 **Clean Visual Design:** Clear representations for processes, decision nodes, and loops.
- 🌐 **Pure Frontend Setup:** Built entirely with lightweight web technologies (HTML, CSS, JavaScript).
- 📱 **Responsive UI:** Works seamlessly across desktop and laptop screens.

---

## 🛠️ Built With

- **HTML5** – Application structure
- **CSS3** – Styling and custom layout
- **JavaScript (ES6+)** – Parsing logic and dynamic DOM manipulation
